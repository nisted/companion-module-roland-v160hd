# companion-module-roland-v160hd (Rebel)

Rebel version of the Roland V-160HD Companion module: base 2.x, Input 1-20 in every destination, named (firmware 3.40+) or low-level commands chosen automatically, a paced command queue that fixes missed button presses with polling on, and presets.

See [HELP.md](./companion/HELP.md) and [LICENSE](./LICENSE).

Part of the Rebels: https://github.com/nisted/companion-modules
